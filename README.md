# AI-Powered Therapist Recommendation Engine

## Overview
A healthcare recommendation system that intelligently matches patients with suitable therapists based on service requirements, specialties, geographical location, language preferences, and scheduling compatibility.

## Problem Statement
Healthcare organizations need an efficient way to identify therapists who best meet individual patient requirements while considering clinical eligibility and operational constraints.

## Proposed Solution
A hybrid recommendation engine combining rule-based filtering, geospatial calculations, and weighted scoring to generate explainable therapist recommendations.

## Technology Stack
- Python
- Pandas & NumPy
- Scikit-learn
- FastAPI
- Geopy
- Pytest

## Core Features
- Service and specialty matching
- Language compatibility
- Geographical distance calculations
- Schedule compatibility
- Weighted recommendation ranking
- Explainable recommendations
- REST API integration
